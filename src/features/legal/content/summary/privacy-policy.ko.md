# tryna 개인정보 처리방침

tryna는 서비스 제공에 필요한 범위에서 개인정보를 처리하고, 불필요한 개인정보를 수집하지 않는 것을 기본 원칙으로 합니다.

---

## 1. 개인정보 처리에 관한 사항

| 구분 | 내용 |
|---|---|
| **처리 목적** | 회원가입·로그인, 일정 관리, 준비물·할 일 관리, AI 기반 일정 분석, 외부 캘린더 연동, 알림, 서비스 안정성 확보 |
| **처리 기간** | 각 정보의 처리 목적이 유지되는 동안 보관하며, 삭제·탈퇴·연동 해제 등으로 목적이 종료되면 삭제하는 것을 원칙으로 합니다. |
| **외부 서비스 이용** | 클라우드, AI API, 외부 캘린더 등 서비스 제공에 필요한 외부 시스템이 사용될 수 있습니다. |
| **이용자의 권리** | 개인정보 열람·수정·삭제·처리정지 요청, 선택동의 철회, 회원 탈퇴, 외부 캘린더 연결 해제 |

---

## 2. 처리하는 개인정보

| 구분 | 처리 항목 |
|---|---|
| **회원정보** | 이메일, 소셜 로그인 계정 식별정보, 서비스 내부 사용자 식별정보 |
| **인증정보** | 로그인 및 인증에 필요한 정보 |
| **일정정보** | 일정 제목, 날짜·시간, 장소, 일정 설명, 반복 설정 |
| **실행정보** | 할 일, 준비물, 완료 여부, 일정과의 연결정보 |
| **AI 이용정보** | 자연어 입력, 일정 구조화 결과, 일정 분석에 필요한 맥락, 추천 결과 및 수정·삭제 정보 |
| **외부 캘린더 정보** | 외부 캘린더·일정 식별정보, 일정 제목, 날짜·시간, 장소, 설명, 반복정보, 동기화 상태, 연결 유지에 필요한 인증정보 |
| **자동 생성정보** | 접속 기록, IP 주소, 브라우저·기기 정보, 오류 및 서비스 이용 기록 |

실제 서비스에서 처리하지 않는 항목은 최종 공개본에서 제외합니다.

---

## 3. 개인정보 이용 목적

| 처리 정보 | 이용 목적 |
|---|---|
| **회원·인증정보** | 회원 식별, 로그인 및 계정 관리 |
| **일정·실행정보** | 일정 및 준비물·할 일 관리 |
| **자연어·AI 이용정보** | 일정 구조화, 일정 맥락 분석 및 준비물·할 일 제안 |
| **외부 캘린더 정보** | 기존 일정 확인, 일정 동기화 및 일정 기반 기능 제공 |
| **자동 생성정보** | 오류 확인, 보안 및 서비스 안정성 개선 |

수집한 정보를 위 목적과 무관한 용도로 사용하지 않습니다.

---

## 4. AI 기능에서의 개인정보 처리

| 구분 | 내용 |
|---|---|
| **이용 목적** | 자연어 일정 이해, 일정 구조화, 준비물·할 일 제안 |
| **처리 범위** | 서비스 제공에 필요한 일정 정보와 맥락 |
| **제외 원칙** | 이메일, 로그인 토큰 등 AI 추론과 관계없는 계정정보는 전달하지 않는 것을 원칙으로 합니다. |
| **모델 학습** | 현재 MVP에서는 이용자의 일정 원문과 자유입력 내용을 외부 AI 모델 학습 목적으로 제공하지 않는 것을 기본 원칙으로 합니다. |

외부 AI API 이용 시 실제 처리업체, 전달정보, 보관 여부 및 국외 처리 여부를 운영 환경 확정 후 공개합니다.

## 5. 외부 캘린더 정보 처리

현재 지원하는 외부 캘린더는 Google Calendar입니다. 자세한 내용은 [Google Calendar 연동 및 데이터 사용 안내](/google-calendar-policy)에서 확인할 수 있습니다.

| 구분 | 내용 |
|---|---|
| **접근 시점** | 이용자가 직접 외부 캘린더 연결을 선택한 경우 |
| **이용 목적** | 기존 일정 확인, 동기화, 일정에 필요한 준비물·할 일 제안 |
| **이용 범위** | 서비스 기능 제공에 필요한 범위 |
| **광고 이용** | 외부 캘린더 정보를 광고 타기팅 또는 판매 목적으로 사용하지 않습니다. |
| **연결 해제** | 이용자는 언제든지 연결을 해제할 수 있습니다. |

## 6. 보유 및 이용기간

| 정보 | 보유 기준 |
|---|---|
| **계정정보** | 회원 탈퇴 시까지 |
| **일정·할 일·준비물** | 이용자가 삭제하거나 회원 탈퇴 시까지 |
| **외부 캘린더 연결정보** | 연결 해제 또는 회원 탈퇴 시까지 |
| **인증정보** | 로그아웃, 만료, 연결 해제 또는 탈퇴 시까지 |
| **운영·보안 로그** | 서비스 운영에 필요한 최소 기간으로 별도 확정 |

관련 법령에 따라 보관이 필요한 정보가 있는 경우 해당 정보만 정해진 기간 동안 별도로 보관할 수 있습니다.

## 7. 개인정보 삭제

개인정보는 다음과 같은 경우 삭제합니다.

- 이용자가 일정 또는 할 일을 삭제한 경우
- 외부 캘린더 연결을 해제한 경우
- 회원 탈퇴가 완료된 경우
- 개인정보의 처리 목적이 종료된 경우
- 보관 기간이 종료된 경우

전자적으로 저장된 개인정보는 복구하기 어려운 방식으로 삭제하는 것을 원칙으로 합니다.

## 8. 개인정보의 외부 처리 및 국외 이전

클라우드, AI API 등 외부 서비스 이용 과정에서 개인정보가 외부 시스템 또는 대한민국 외의 서버에서 처리될 수 있습니다.

실제 외부 처리 또는 국외 이전이 발생하는 경우 처리 대상, 목적, 국가, 보유기간 등 관련 법령에서 요구하는 내용을 확인하여 공개합니다.

- 불필요한 개인정보 처리 최소화
